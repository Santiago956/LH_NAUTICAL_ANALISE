# Questao 3 - Carregamento

## Cenario

Apos a criacao do schema, os CSVs precisam ser carregados em um banco de dados bruto para facilitar as analises posteriores.

## Restricoes

- Realizar o carregamento de todos os CSVs.
- Usar obrigatoriamente Python 3.
- Usar qualquer biblioteca necessaria para conexao e carregamento.
- Nao fazer tratamentos como remocao de nulos ou correcao de caracteres especiais.

## Tarefa

Escrever um script Python para carregar todos os arquivos CSV respeitando o schema criado na questao anterior.
